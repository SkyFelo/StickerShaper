# Telegram StickerShaper Bot

Простой бот на C#, который подгоняет изображения под требования Telegram для стикеров.  
Создан для удобного редактирования картинок с любого устройства без использования сторонних программ.

---

## Описание

Бот принимает изображение (как фото или файл), автоматически изменяет размер под формат **512×512** и отправляет готовый PNG-файл обратно.  
Если картинка почти квадратная — делается квадрат 512×512.  
Если прямоугольная — масштабируется так, чтобы обе стороны вписывались в квадрат 512×512, сохраняя пропорции.

---

## Используемые технологии

- **C# (.NET 6 / .NET 8)**  
- **Telegram.Bot** — для взаимодействия с Telegram API  
- **SixLabors.ImageSharp** — для обработки изображений
